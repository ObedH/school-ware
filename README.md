# SchoolWare

**SchoolWare is a short WarioWare-stye puzzle game where you have to complete 
school-related tasks in a limited amount of time.**

*This project was made for [Hack Club Stardance](https://stardance.hackclub.com/).*

## How to Play
[![Try it]()](http://obedh.itch.io/school-ware)
Click the link above and press Run Game.

More instructions and controls can be found in the description of the itch.io 
page.

## Features
1. Three fast-paced minigames that involve school subjects like History, Pre
Algebra, and Biology.
2. A timer that keeps track of your fastest time, so you can go back and try to 
beat your record
3. Pixel art graphics using the NES color palette

## AI Usage
No generative artificial intelligence was used for any part of this project.
